统一换算方法与假设
  1. 汇率：统一按 1 USD = 7.1 CNY 折算（2026 年 8 月大致水平，实际以支付渠道实时汇率为准）。
  2. 月度 tokens 估算：各家套餐官方计量口径不同（prompts / 次请求 / Credits / 美元额度 / 直接 token），本报告统一换算为「估算月度可用 tokens」：
    • 官方直接公布 token 数（如 Kimi 国内版 500 万 / 2,000 万 tokens/月）：直接采用；
    • 官方公布倍率（如智谱 Lite=3×Claude Pro、Pro=5×Lite、Max=20×Lite；火山方舟 Pro=5×Lite）：以 Claude Pro ≈ 350 万 tokens/月（API 等值，参考 Anthropic 收支平衡点约 370 万）为锚点线性推算；
    • 美元用量额度型（Cursor $20 额度、Copilot $15~$200 AI Credits、CodeBuddy 积分）：按主流模型混合 API 费率约 $5/百万 tokens 折算；
    • 会话/窗口限制型（Claude、ChatGPT、Gemini、Grok、Windsurf）：参考第三方收支平衡分析估算；
    • 按量 API（DeepSeek）：不参与订阅排名，仅在模型查询页作为按量参考基准。
  3. 模型消耗倍率：指在某套餐内调用该模型时相对基准模型的额度消耗倍数（如智谱 GLM-5.2 / GLM-5-Turbo 高峰期 14:00-18:00 按 3x 扣额度、GitHub Copilot 调用 Claude Opus 4.6 一次扣 3 次高级请求等）。模型查询页单价 = 月费 × 优惠因子 ÷（估算 tokens ÷ 倍率），与排名页同一口径，仅额外扣除模型消耗倍率。
  4. 估算局限：订阅额度普遍存在「5 小时窗口 + 周限额」双重限制，实际可用量取决于使用强度与时段分布；本报告按中高强度利用（每天约 1.5~2 个满窗口）估算，轻度用户实际单价会偏高。估算值不代表官方承诺。
  5. 价格口径（排名）：排名与本报告各处「折合单价」统一采用「标准月付价 × 优惠因子 ÷ 月度 tokens」；其中带 首月优惠（firstMonth，如「首月 ¥9.9」「首两月 ¥9.9」「首月免费」）的套餐，排名改按首月实付价 ÷ 月度 tokens折算并特别标注「首月」，次月起恢复标准月付价。其余字段（标准月价、年付折扣）仍照常展示。其中：
    • 缓存说明：报告不含缓存放大——订阅内模型调用若存在提示词缓存，有缓存时实际可用量会更多，但本报告采用不含缓存的保守估算以避免高估额度。
    • 优惠因子（国内折价，`disc`）：在标准月价之上叠加各厂商官方促销——智谱 GLM 取「ZCode 50% × 连续包年 7 折 × 非高峰」≈0.175（GLM-5.3 Pro 折合约 0.119 元/M）；MiniMax 连续包年约 0.833；小米 MiMo 夜间 0.8× × 连续包年 88 折≈0.704；Kimi 国内连续包年约 0.8。其余无官方季/年折的套餐优惠因子=1。
    • 「按公司浏览」页的月卡/季卡/年卡切换：月=标准月付，季/年=官方折算月均价（有则用之，无则按原价计并显示整档总金额），仅影响该页展示，不改变排名口径。
  6. 折合单价口径：本报告统一采用「月费 × 优惠因子 ÷ 估算月度可用 tokens」，不含缓存放大（有缓存时实际可用量更多）。纯按量 API（如 DeepSeek）不参与订阅排名，仅在「按模型查询」页作按量参考基准。
