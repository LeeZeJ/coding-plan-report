统一换算方法与假设
  1. 汇率：统一按 1 USD = 7.1 CNY 折算（2026 年 8 月大致水平，实际以支付渠道实时汇率为准）。
  2. 月度 tokens 估算：各家套餐官方计量口径不同（prompts / 次请求 / Credits / 美元额度 / 直接 token），本报告统一换算为「估算月度可用 tokens」：
    • 官方直接公布 token 数（如 Kimi 国内版 500 万 / 2,000 万 tokens/月）：直接采用；
    • 官方公布倍率（如智谱 Lite=3×Claude Pro、Pro=5×Lite、Max=20×Lite；火山方舟 Pro=5×Lite）：以 Claude Pro ≈ 350 万 tokens/月（API 等值，参考 Anthropic 收支平衡点约 370 万）为锚点线性推算；
    • 美元用量额度型（Cursor $20 额度、Copilot $15~$200 AI Credits、CodeBuddy 积分）：按主流模型混合 API 费率约 $5/百万 tokens 折算；
    • 会话/窗口限制型（Claude、ChatGPT、Gemini、Grok、Windsurf）：参考第三方收支平衡分析估算；
    • 按量 API（DeepSeek）：不参与订阅排名，仅在模型查询页作为按量参考基准。
  3. 模型消耗倍率：指在某套餐内调用该模型时相对基准模型的额度消耗倍数（如智谱 GLM-5.2 / GLM-5-Turbo 高峰期 14:00-18:00 按 3x 扣额度、GitHub Copilot 调用 Claude Opus 4.6 一次扣 3 次高级请求等）。模型查询页单价 = 月费 ÷（估算 tokens ÷ 倍率）。
  4. 估算局限：订阅额度普遍存在「5 小时窗口 + 周限额」双重限制，实际可用量取决于使用强度与时段分布；本报告按中高强度利用（每天约 1.5~2 个满窗口）估算，轻度用户实际单价会偏高。估算值不代表官方承诺。
  5. 价格口径：均采用标准月付价；连续包月 / 包季 / 包年折扣、首月优惠、早鸟价、限时活动（如智谱每日 10:00 限量发售、百炼早鸟价）单独标注，不参与排名计算。
